01 / The Problem & The Core Innovation

Why Legacy [REDACTED] Breaks Enterprise AI

Traditional DLP tools strip sensitive tokens into irreversible [REDACTED] blocks—destroying variable relationships, breaking code generation, and confusing LLM reasoning. DOST replaces them with structured, reversible pseudonyms.

✕ Legacy DLP Appliances

Destructive Redaction

Replacing every secret, Person ID, or company codename with [REDACTED] erases semantic links across a prompt or codebase.

  • ❌Ruins LLM Reasoning: The model cannot distinguish between multiple [REDACTED] entities.
  • ❌Breaks Code Generation: Cursor and Claude Code output invalid syntax or broken identifiers.
  • ❌High Friction: Frustrated engineers bypass security controls to get work done.
✓ DOST Privacy Proxy

Silent, Stateful, Reversible Pseudonymization

Outbound sensitive entities are swapped with structured placeholders (e.g., Company_Alpha, Person_ID_01) and seamlessly restored on the inbound SSE stream.

  • ✅Preserves Full Context: LLMs reason over consistent, type-safe placeholders.
  • ✅Real-Time SSE Restoration: Sliding-window micro-buffer swaps placeholders back into real values in flight.
  • ✅Invisible Guardian Angel: Zero UI clutter or workflow obstruction for employees and agents.

02 / Core Capabilities

The 4 Pillars of DOST

A 2-stage hybrid detection and streaming pipeline engineered for line-rate performance and zero developer friction.

🔍
Pillar 01 · D

Detect

Microsecond Stage-1

Microsecond 2-stage scanning combining deterministic pattern matching (Google RE2 & Aho-Corasick automata) with GLiNER entity extraction—catching API keys, PII, and internal codenames while filtering out false positives.

Aho-Corasick Google RE2 GLiNER False-Positive Filter
👁️
Pillar 02 · O

Observe

Millisecond Stage-2

Millisecond ML model classification using quantized tiny ML models (GLiNER & GLiClass) to evaluate semantic context and determine whether candidate entities are genuinely confidential enterprise data or benign public context.

Quantized GLiClass Contextual Sensitivity Zero-Shot Classification
🛡️
Pillar 03 · S

Shield

Stateful Vault

Reversible pseudonymization of private data that shouldn't leave the organization—such as Person ID, customer records, internal project codenames, and credentials—swapping them with structured placeholders like Company_Alpha or Person_ID_01.

Reversible Pseudonyms Person ID Protection Session State Map
⚡
Pillar 04 · T

Transfer

< 20ms SSE Stream

Sliding-window Server-Sent Events (SSE) micro-buffer restoring real values on inbound traffic with sub-20ms latency. Works seamlessly across all LLM providers without obstructing agentic workflows—no UI clutter, just an invisible guardian angel securing company data.

Sliding-Window SSE Sub-20ms Latency All LLM Providers Agent-Ready
