01 Reversible DLP

Masks PII and internal references outbound and restores them inline as responses stream back, keeping recognized credentials out of the reversible map.

02 MCP & Skill Admission

Checks publisher, permissions, instructions, scripts, and dependencies before any skill, MCP server, extension, or package activates.

03 Injection & Tool Guardrails

Treats web fetches, tool outputs, and MCP descriptions as untrusted input and enforces scoped identities and side effects outside the model.

04 Explicit Route Coverage

Works across any provider or coding client and reports every route honestly as Enforced, Observed, or Uncovered.
